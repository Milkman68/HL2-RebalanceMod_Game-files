# HL2 Rebalanced
The Github Repository for the Sourcemod portion of the mod.
The Sourcecode can be found [here](https://github.com/mariovct/HL2-RebalanceMod).

## ============What is this?============
This repository is just for keeping a backup and feature-tracked version of the Sourcemod files for HL2R. The main vpk is uncompiled, so you need to use vpk.exe on it if you're planning on running a download of this. Downloading HL2R from the Moddb page is recommended.
